# Portfolio + Demo Website Starter Pack

This folder contains two beginner-friendly websites:
- `portfolio/` — personal developer + designer portfolio
- `cafe-demo/` — fictional cafe business website concept

## Run on your Mac
1. Download and unzip the pack.
2. Open the unzipped folder in VS Code.
3. Open either `portfolio/index.html` or `cafe-demo/index.html`.
4. If you have the Live Server extension, right-click `index.html` and choose **Open with Live Server**. Or open the HTML file directly in your browser.

## Personalise before sharing
### Portfolio
- Replace `Your Name`, `yourname`, the sample email and social links.
- Replace sample project descriptions with projects you have genuinely built.
- Replace design concept tiles with your own Canva/Figma work before describing them as your own.
- Add working links to your actual project demos.

### Cafe demo
- This is a fictional business concept. Menu items, prices, address, hours and contact details are placeholders.
- Keep it clearly labelled as a concept project unless a real business has approved the content.
- You may use it as a portfolio demo to show layout and responsive design skills.

## Publish for free
For the portfolio, create a GitHub repository and upload the contents of the `portfolio` folder. In repository Settings → Pages, choose deployment from the `main` branch and root folder. GitHub will display the published URL after deployment. You can publish the cafe demo in its own repository too.

Google Fonts are loaded from the internet; if unavailable, the pages fall back to system fonts. No build tools or paid services are required.
